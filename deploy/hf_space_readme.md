# HireAI

AI resume screening with explainable scores and a recruiter dashboard.

Create a job, upload resumes (`.txt`, `.pdf`, `.docx`), and every candidate gets a 0–100 score with matched and missing skills.

**This is a public demo.** There is no login, and anyone with the link can see and change the data. Upload only sample resumes, never real people's. Data resets whenever the Space restarts.

Source code and full documentation: https://github.com/MuthuVarshith/Hire-AI
